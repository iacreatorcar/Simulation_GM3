SIMULATION GM3

Console luci da browser, ispirata al workflow grandMA3
Solo uso dimostrativo / training interno

Simulation GM3 è un simulatore di consolle luci che gira interamente nel browser: nessuna installazione, nessun hardware dedicato, nessuna licenza software. Riproduce il flusso di lavoro base di una consolle da moving-light — patch, cue, playback, automazione — per far esercitare velocemente un operatore su concetti e comandi reali prima di toccare una console vera.

Perché

Formazione senza hardware

Chi si avvicina a una consolle luci può esercitarsi su patch, cue e playback senza prenotare una console fisica.

Zero setup

npm install && npm start e si apre nel browser. Nessuna dipendenza frontend, nessun build step.

Concetti trasferibili

Command line, patch fixture, cue con effetto automatico, master/slave: stessa logica delle console professionali.

Come funziona (in breve)

Patch fixture→ Imposta fader→ Store Cue / Scene→ GO / Automation→ Stage View live

Cosa include

16 canali

Fader drag/click, mouse e touch, con LED di stato.

Patch & Fixture Sheet

12 tipi di fixture (PAR, Moving Head, Wash, Mirror Ball, Fog, Blinder...).

Cue Pool con effetti

Ogni cue può portare un effetto automatico (chaser/rainbow/strobe) al GO.

Stage View

Simulatore a canvas: fasci diversi per tipo di fixture, truss, palco.

Design Creator

Assegna colori per canale e salva il "look" come Design riutilizzabile.

Catalyst

Pannello media server (4 layer, blend, opacità) con preview composita reale.

Timecode

Sequenza automatica a tempo, richiama scene/effetti a marcatori prestabiliti.

Command line + keypad

AT, FULL, OFF, CLEAR, tastierino fisico su schermo.

Nota: il progetto è pensato per demo e training interno. Le cue vivono in memoria sul server (si perdono al riavvio), scene/patch/design vivono nel localStorage del browser. Non è pensato per uso multi-utente in produzione — dettagli e percorso di scalabilità in scheda tecnica.
