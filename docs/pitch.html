SIMULATION GM3

A browser-based lighting console, inspired by the grandMA3 workflow
Demo / internal training use only

Simulation GM3 is a lighting console simulator that runs entirely in the browser: no installation, no dedicated hardware, no software license. It reproduces the core workflow of a moving-light console — patch, cue, playback, automation — so an operator can quickly practice real concepts and commands before touching an actual console.

Why

Training without hardware

Anyone approaching a lighting console can practice patch, cues and playback without booking a physical console.

Zero setup

npm install && npm start and it opens in the browser. No frontend dependencies, no build step.

Transferable concepts

Command line, fixture patch, cues with automated effects, master/slave: the same logic as professional consoles.

How it works (in short)

Patch fixture→ Set faders→ Store Cue / Scene→ GO / Automation→ Live Stage View

What's included

16 channels

Drag/click faders, mouse and touch, with status LEDs.

Patch & Fixture Sheet

12 fixture types (PAR, Moving Head, Wash, Mirror Ball, Fog, Blinder...).

Cue Pool with effects

Each cue can carry an automated effect (chaser/rainbow/strobe) on GO.

Stage View

Canvas simulator: different beams per fixture type, truss, stage floor.

Design Creator

Assign colors per channel and save the "look" as a reusable Design.

Catalyst

Media-server panel (4 layers, blend, opacity) with a real composited preview.

Timecode

Time-based sequence, fires scenes/effects at pre-set marks.

Command line + keypad

AT, FULL, OFF, CLEAR, physical on-screen keypad.

Note: the project is intended for demos and internal training. Cues live in real time on Supabase (Postgres + Realtime), while scenes/patch/design live in the browser's localStorage. It's not intended for multi-tenant production use — details and scalability path in the technical sheet.
